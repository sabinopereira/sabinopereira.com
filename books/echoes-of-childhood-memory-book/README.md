# Echoes of Childhood — A Memory Book

Premium editorial companion to the album *Echoes of Childhood*.

## Credits

- Music: RB / Reira Bin
- Book and text: SP / Sabino Pereira

## Production status

The Final Manuscript and the premium eBook edition are complete. The official author-supplied cover is paired with twelve bespoke chapter illustrations developed from the supplied visual reference boards. The overview boards themselves are not used as interior pages. The edition contains no QR codes or music links and is organised into two parts: **Where It All Began** and **The Echoes We Carry**.

Final eBook: `output/echoes-of-childhood-a-memory-book-premium-ebook.pdf`

## Directory map

- `manuscript/` — canonical text and chapter sources
- `editorial/` — editorial brief, revision reports, and manuscript decisions
- `visual/` — visual system, page architecture, and illustration direction
- `assets/cover/` — official supplied cover source
- `assets/illustrations/` — approved chapter artwork
- `build/` — intermediate rendered files
- `output/` — approved digital and print deliverables
- `scripts/` — deterministic build and validation tools

No new book project should begin before this project reaches final-manuscript and production-ready status.
